## 일시, 완료 상태
대회 날짜는 2026년 10월 17일, 본선 진출에 실패했으므로 현재 상태는 완료 상태입니다.
## 목표/목적
본선 진출을 목표로 하였으며 PS실력 증진 및 순수 재미 목적으로 참가함.  
수상시 수상경력에 적을 수 있다는 부분은 부차적인 목적
## 주요 결과
본선 진출은 실패  
1 solve로 전북대학교 내에서는 4등으로 특별상 수상
## 원인과 아쉬운 점
1. g번 문제의 조건을 착각하여 너무 오랜 시간을 낭비했다는 점  
-> 문제의 조건을 더 꼼꼼히 읽고 대회 전 피로도 및 멘탈을 관리할 것
2. 문제 조건의 착각(지각 오류)일 가능성이 높다는 점을 알면서도 문제를 놓지 않은 점  
-> 지각 오류로 보이는 문제라면 일단 패스 후에 머리를 식히고 다시 풀기
3. 팀원 실력에 맞춘 문제 분배에 실패한 점  
-> 특정 문제의 난이도가 해당 팀원 수준보다 고난이도일 경우, 다른 문제를 풀도록 적극적으로 권유할 것
## 본인의 역할 및 결과
팀장으로서 어려운 문제를 해결하는 것이 원래 역할이었으나 쉬운 문제인 g번에서 시간을 지나치게 끌려 1문제밖에 풀지 못함.
## g번 문제 풀이의 방식
문제는 다음 링크와 같습니다.  
https://jungol.co.kr/problem/26864?cursor=IjQ4NyIsMCw2
해당 문제는 그리디 알고리즘을 사용하는 방식으로 앞에서부터 자음과 모음의 조합이 하나의 글자를 이루도록 묶어가면서 대응시킬 수 없는 문자가 나오거나 남은 문자로는 타당한 분리 구성을 만들 수 없는 경우, 에러를 출력하면 됩니다.  
그리디를 사용한 이유는 영어 수열 a = 앞의 한 문자 단위 + a' 로 구성하였을 때, a가 한글로 치환 가능한 배열이라면 앞에서 적당한 한 문자 단위를 떼어내면 한글로 치환 가능한 나머지 배열 a'를 얻을 수 있으며 하나의 한글은 2개 혹은 3개의 알파벳으로 구성되며 떼어낼 적절한 하나의 문자 단위는 a'의 처음 2개가 초성 + 중성 형태를 만족하도록 만드는 것이기 때문입니다.  
에러를 출력하는 경우는 다음과 같습니다.
1. 첫문자가 모음인 경우
2. 첫문자가 자음인데 두번째 문자도 자음이거나 없는 경우
3. 첫문자가 자음, 두번째 문자가 모음인데 세번째 문자도 모음인 경우
4. 자음/모음으로 대응시킬 수 없는 문자가 등장하는 경우  

경계면을 정하는 방법은 다음과 같습니다.
1. 첫문자가 자음, 두번째 문자가 모음, 세번째 문자부터 없는 경우
-> 첫번째와 두번째를 하나의 글자 단위로 본다. 이후 종료한다.
2. 첫문자가 자음, 두번째 문자가 모음, 세번째 문자가 자음, 네번째 문자가 모음인 경우  
-> 첫번째와 두번째를 하나의 글자 단위로 본다. 이후 시작점을 세번째로 옮겨서 재검사한다.
3. 첫문자가 자음, 두번째 문자가 모음, 세번째 문자가 자음, 네번째 문자가 자음이거나 없는 경우 
-> 첫번째와 두번째, 세번째를 하나의 글자 단위로 본다. 이후 시작점을 네번째로 옮겨서 재검사한다.(네번째 문자가 없다면 검사를 종료한다.)
